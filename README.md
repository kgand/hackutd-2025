# Magenta

A real-time customer sentiment monitoring platform for T-Mobile that aggregates social media data, performs location-based analysis, and provides interactive visualizations.

## Overview

Magenta is a full-stack application that:
- Scrapes Twitter data for T-Mobile-related topics
- Detects service outages via DownDetector
- Uses AI to analyze and summarize customer feedback
- Provides interactive map and graph visualizations

## Technology Stack

- **Frontend**: React, TypeScript, Vite, TailwindCSS, Deck.gl, D3.js
- **Backend**: Express, TypeScript, Python
- **Database**: Supabase (PostgreSQL)
- **APIs**: Apify (Twitter), Google Gemini (AI)
